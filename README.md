# Madaaris – Qur'an School Management System

Madaaris is a Somali-first, English-ready multi-tenant school management application. This repository contains an Angular frontend and Laravel REST API. The current MVP foundation includes Sanctum token authentication, tenant and branch enforcement, live dashboard metrics, student registration/listing, duplicate-safe attendance submission, Qur'an assignment storage, invoice/payment storage, transactional idempotent payments, and append-only audit storage.

## Requirements

- Node.js 22+ and npm
- PHP 8.3+ with PDO MySQL, mbstring, openssl, tokenizer, XML, ctype, JSON and fileinfo
- Composer 2
- MySQL 8, database named `Madaaris`, InnoDB and utf8mb4

The workstation used for initial verification has PHP 8.2.12, so Laravel 12 was selected. Production should use PHP 8.3+ as specified.

## Installation

Backend:

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Set MySQL credentials in `backend/.env`. To create the optional local demo administrator, set `DEMO_ADMIN_PASSWORD` before seeding. No password is committed or generated by a production seeder.

Frontend:

```bash
cd frontend
npm install
ng serve
```

During development, proxy `/api` to Laravel at `http://127.0.0.1:8000`. In production, serve both applications behind the same HTTPS origin or configure CORS and Sanctum explicitly.

## Verification

```bash
cd backend && php artisan test
cd frontend && npm run build
```

## Production build

```bash
cd frontend
ng build --configuration production

cd ../backend
composer install --no-dev --optimize-autoloader
php artisan config:cache
php artisan route:cache
php artisan view:cache
```
